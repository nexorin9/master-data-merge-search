# 输出样例集、基准实测与状态口径

本文是 README「输出样例」与「概念 / 实测对照」的展开。所有编码、记录编号均为 `tests/fixtures/corpus` 的确定性仿真语料，非任何真实患者或院内数据。

## 归并建议 JSON（真实切片产物形态）

`pnpm tsx scripts/run-merge.ts --limit 8` 产出 `outputs/sample-batch/suggestions.json`。未配置真实模型端点时，唯一命中类候选走确定性降级，结论为 `uncertain + degraded=true`，置信度封顶 0.5，只作待人工处理、不可写回：

```json
{
  "candidate_id": "CAND-ALIAS-001",
  "domain": "drug",
  "action": "uncertain",
  "target_code": null,
  "confidence": 0.5,
  "rationale": "",
  "evidence": [
    {
      "record_id": "MD-000147",
      "field": "insurance_code",
      "candidate_value": "XJ7000000000146",
      "matched_value": "XJ7000000000146"
    }
  ],
  "uncertain_reason": "模型不可用",
  "degraded": true,
  "decided_at": "2024-07-01T09:30:00.000Z"
}
```

`action` 只有三种取值：`create`（新建）、`merge`（并入哪一条）、`uncertain`（存疑）。存疑时 `uncertain_reason` 必填，取值来自固定枚举：`多义命中 / 关键字段缺失 / 无近似项 / 版本冲突 / 模型输出不合法 / 检索失败 / 模型不可用 / 命中记录均已停用`。降级结论另带 `capped_from` 与 `capped_by`，说明置信度为何被封顶，防止被误读为决策级高把握。

## 归并建议单 CSV（列序固定，与审计链导出同口径）

```csv
时间,candidate_id,action,target_code,置信度,证据条数,确认人,回执状态
2026-01-01 09:30,样例候选-001,merge,样例主数据编码-001,0.93,2,数据治理专员,成功
2026-01-01 09:30,样例候选-002,uncertain,,0.50,3,数据治理专员,失败:候选已被平台侧驳回
```

导出前做姓名 / 证件号 / 患者号形态扫描；命中行拒收并在回执说明原因，不整批阻塞、也不把脏行写进建议单。

## 基准对拍实测（160 条人工标注）

`pnpm tsx scripts/compare_benchmark.ts` 在同一份基准集上跑两条路径，产出 `reports/benchmark/compare-report.json` 与 `.md`。基准集构成：期望归并 64、期望非归并 96、期望存疑 32（同义改名 / 同名异规格 / 换单位 / 停用码 / 医保码错配各 32 条）。

| 路径 | 命中率 | 错误归并率 | 漏并率 | 存疑率 | 结论 |
|------|--------|------------|--------|--------|------|
| A · 字面相似度基线（Excel 模糊比对等价物） | 0.40 | 0.60 | 0 | 0 | 不放量 |
| B · 检索增强 + 模型 | 0.60 | 0 | 0.40 | 0.60 | 未验证 |

- **路径 A 的错误归并率 0.60 是核心发现**：把 96 条不该并的并了（多为医保码错配 / 停用码），基线的固有缺陷是复合键不校验、排序只取首条。错误归并率 > 0，按放量阈值判 **不放量**，报告逐条列出 96 个错误归并候选。
- **路径 B 未实连**：离线环境无真实模型端点，报告显式标注「模型路径未实连，仅基线可核验」，结论为「未验证」而非「通过」，绝不拿基线数据冒充模型结论。其错误归并率为 0、漏并率 0.40，是「保守转存疑」的可核验证据，但未经真实模型验证不得放量。
- **码制口径对照**：`reports/benchmark/code-rules-check.md` 如实标注「未完成（权威码制文件缺失）」——权威 docx（医保发〔2019〕55 号附件）不在本仓库，故不编造码制位义条文。
- **可复现**：固定时钟 + 确定性种子 20240433；同输入连跑两次指标误差 0，报告写明样本量 160 与数据集版本。

## 关键状态口径

| 维度 | 口径 |
|------|------|
| 复合键 | `domain + insurance_code + spec + dosage_form + unit`，规格单位归一后比较（250mg*12片 ≡ 0.25g*12片），跨维度不换算 |
| 三态 | `create / merge / uncertain`；多义命中、关键字段缺失、停用码、版本冲突、检索失败、模型不可用、证据越界、schema 校验失败一律转 `uncertain` |
| 检索失败 | 显式报错并阻断结论，绝不以空结果冒充「无近似项」 |
| 幂等键 | `sha256(candidate_id｜actionHash)`，与时间戳、重试次数无关；重放只记「跳过」 |
| 撤回 | 追加一条带 `supersedes` 的新建议，历史条目一律保留，审计链只增不改 |
| 写回 | 逐条人工勾选确认；降级结论写回层恒拒绝；候选状态始终由主数据平台侧人工推进 |
